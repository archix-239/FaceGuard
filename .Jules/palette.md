## 2025-05-22 - Dashboard Surveillance Industrielle
**Learning:** In high-stress security environments (24/7 booth), dark mode with high-contrast accents (emerald/amber/destructive) is essential for rapid situational awareness without eye strain.
**Action:** Use "Threat Level Gauges" with both color and textual state indicators to ensure accessibility for colorblind users and clear hierarchy in a glance.

## 2025-05-22 - Triage des Alertes IA
**Learning:** Human-in-the-loop UX should prioritize "Assistance" over "Automation". Providing a ±3s replay and the "AI Reason" helps agents build trust with the system and reduces cognitive load during triage.
**Action:** Always include a brief textual explanation of AI decisions in administrative interfaces.
